# quest-relationships-database
# 🔐 Квест «Таємниця бібліотеки школи»

Інтерактивний навчальний квест з інформатики для учнів 9 класу на тему **«Види зв'язків у реляційних базах даних»**.

Сюжет: зник бібліотекар, а в сейфі лежить пароль до бази даних шкільної бібліотеки. Щоб відкрити сейф, учень проходить 4 кімнати й здобуває 4 ключі. Кімнати проходять по черзі: рухатись далі можна лише після правильної відповіді.

## Рівні

| № | Кімната | Завдання |
|---|---------|----------|
| 1 | Архів ключів | Позначити в таблицях первинні та зовнішні ключі. |
| 2 | Читальна зала | Визначити тип зв'язку («один до одного», «один до багатьох», «багато до багатьох») для 8 життєвих ситуацій. |
| 3 | Стелаж-павутина | З'єднати записи таблиць лініями за умовою, потім обрати тип зв'язку, що вийшов. |
| 4 | Кабінет бібліотекаря | Знайти хибні твердження у схемі бази даних. |

## Оцінювання

- Кожна кімната дає до **25 балів**, разом **100**.
- Кожна помилка знімає частину балів. Рівень можна виправляти, поки відповіді не стануть правильними.
- Звання за підсумком: Новачок (менше 50), Практикант (від 50), Бібліотекар-профі (від 70), Головний архітектор БД (від 90).

## Результати

На фінальному екрані учень бачить своє прізвище, ім'я, клас, бали, звання та список допущених помилок. Доступні дві дії:

- **Зберегти результат** — завантажує зображення з підсумком.
- **Надіслати вчителю** — надсилає результат у Google-таблицю через Google Apps Script.

У таблицю передаються поля: `Прізвище`, `Ім'я`, `Клас`, `Бали`, `Макс. балів`, `Кількість помилок`, `Підсумок по рівнях`, `Допущені помилки`, а також зображення підсумку.

## Як змінити зміст

Усі тексти завдань зібрано на початку скрипта:

| Змінна | Що містить |
|--------|------------|
| `T1` | Таблиці й поля для рівня 1 (`pk` — первинний ключ, `fk` — зовнішній, порожнє значення — звичайне поле). |
| `Q2` | Ситуації рівня 2: текст, правильний тип (0 — 1:1, 1 — 1:∞, 2 — ∞:∞), пояснення. |
| `R3` | Три раунди рівня 3: записи, умови, правильні лінії `"i-j"`, тип зв'язку. |
| `S4` | Твердження рівня 4: текст і ознака, чи є воно хибним (`1` — хибне). |

Якщо змінюєте кількість пунктів, оновіть також масив `N` (кількість пунктів на кожному рівні для підрахунку балів).

## Технічно

Це один файл HTML без зовнішніх бібліотек: працює на комп'ютері, планшеті й телефоні, не потребує сервера, окрім надсилання результатів.
